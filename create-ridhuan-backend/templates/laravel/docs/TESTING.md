# Final acceptance protocol

Implementation, native package/autoload/OpenAPI artifacts, Docker app/web images and root CLI build must finish before testing. Author complete stage scripts first: assertions/fixtures/timeouts/error collection/report/finally cleanup. Run node scripts/verify.mjs --stage native then --stage integration; root adapters verify generated projects/tarball/Compose. Independent gates continue on nonzero exit, aggregate FAILED; dependent API prerequisites abort their scenario.

Required inventory: Windows/Linux PHP64/extensions/Composer validate/audit/Pint/Larastan/PHPUnit/config+route cache; both provider fresh/upgrade/checksum/seed; auth15m/sliding30d/replay/consumed logout/concurrency/inactive/RBAC/audit savepoint fault; all33 OpenAPI/resource/envelope/status operations; generated module strict build; local/S3 upload/download/compensation/private docroot; file FPM and shared Redis quotas/outage/cache auth+invalidation; ordered51/120 SSE/cursors/isolation/inactive/disconnect/admission/outage; two child outbox blocking-renewal/SMTP retry/lease/fencing/shutdown; cleanup dry/apply retention/orphans; OTel off/on/outage/redaction. Root matrix covers seven frameworks x2 providers, Windows/Linux consumers, macOS smoke and Compose. Evidence is explicit per-case, not an inferred green from config.

Every Docker fixture uses a unique project/resource prefix, owns labels/ports and cleans down -v --remove-orphans, its image tags, then verifies no project containers/networks/volumes remain. Never global prune. Logs remain OS TEMP outside npm payload. On failures group root causes, repair affected groups, rerun affected gates first then complete verification; bounded retries.
