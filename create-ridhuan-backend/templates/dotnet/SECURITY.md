# Security policy

## Supported versions

Security fixes are provided for the latest released version on the `main` branch. Older generated projects are not updated automatically; apply the relevant changes and dependency updates to your copy.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/RidhuanDEV/NET-backend/security/advisories/new). Include the affected commit or version, impact, and steps to reproduce. Avoid public issues for unpatched vulnerabilities. The maintainers will acknowledge the report as soon as practical and coordinate a fix and disclosure with the reporter.

Do not include real credentials, production data, or personal information in a report.
