# Pelaporan kerentanan

Jangan membuat issue publik yang berisi exploit, secret, atau langkah reproduksi yang dapat membahayakan pengguna.

Gunakan fitur private vulnerability reporting/GitHub Security Advisory pada repository ini bila tersedia. Sertakan versi atau commit yang terdampak, dampak, prasyarat, dan langkah reproduksi minimum tanpa data pengguna. Jika pelaporan privat belum aktif, hubungi maintainer melalui kanal privat GitHub sebelum mempublikasikan detail teknis.

Belum ada SLA respons atau kebijakan bounty yang ditetapkan. Jangan mengirim credential atau data pribadi dalam laporan.
